# Картка для climate.1e64a41d

[Готова YAML-картка](lovelace-card-1e64a41d.yaml), [копія JSON](lovelace-card-1e64a41d.json).

Картка зберігає entity_id із раніше наданого списку. Історичні фрагменти `demo` та старі англійські назви можуть залишатися в реєстрі HA після оновлення інтеграції; перейменовувати їх для використання картки не потрібно.

Вгорі є вибір чотирьох статусів, а у повідомленні про тимчасове блокування — вибір статусу для дострокового розблокування. В енергетичному балансі показані заряд для зупинки та заряд для відновлення роботи. Окреме повідомлення пояснює очікування верхнього порога заряду. Є налаштування, причини рішень, помилки, прогноз, таймери та графіки за 12 годин.

Спочатку оновіть інтеграцію та перезапустіть HA. Потім вставте весь YAML у **Редагувати панель → Додати картку → Вручну** або замініть YAML наявної картки. Це одна vertical-stack картка, а не конфігурація всієї панелі. Оновлення інтеграції не оновлює збережену картку автоматично.

Нові сутності для порогів не потрібні: картка читає `minimum_soc` і `restart_soc` з атрибутів наявного енергетичного дозволу. Якщо сутності були перейменовані після наданого списку, звірте ID за [інструкцією](dashboard-card.md).
