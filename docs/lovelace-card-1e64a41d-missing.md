# Сутності, яких бракує

У [підготовленій картці](lovelace-card-1e64a41d.yaml) підтверджено 20 entity_id зі старої картки. Для завершення потрібні фактичні ID наступних 6 сутностей:

| Місце підстановки | Назва сутності |
|---|---|
| `binary_sensor.scm_command_failed` | Помилка управління кондиціонером |
| `binary_sensor.scm_running` | Кондиціонер увімкнено |
| `select.scm_operation_mode` | Режим роботи |
| `sensor.scm_command_error` | Помилка команди кондиціонеру |
| `sensor.scm_energy_reason` | Причина енергетичного дозволу |
| `sensor.scm_strategy_action` | Рішення стратегії |

У вихідній картці є попередній перемикач і попередні датчики дії та роботи. Їх не використано для нових сутностей: після зміни ключа unique_id це інші записи реєстру. Датчики причини, енергетичного дозволу й таймерів зберегли ключі unique_id, тому їхні старі entity_id використано буквально, навіть якщо назва ID історична. Назви в самій картці відповідають поточній роботі.

Повний список зі встановленого HA показує попередню версію 0.2.6 (commit ce27811). У ній немає перелічених шести нових сутностей. Спочатку потрібно встановити поточні файли 0.3.2 і перезапустити HA; після цього фактичні ID можна буде підставити в картку.
