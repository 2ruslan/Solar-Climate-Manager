# Оновлення до 0.4.1

[Архів інтеграції](solar-climate-manager-0.4.1.zip) містить каталог custom_components/solar_climate_manager. Архів призначений для ручного встановлення. Для встановлення через HACS оновіть або повторно завантажте Solar Climate Manager із репозиторію та перезапустіть HA; кроки нижче потрібні лише для ручного способу.

1. Збережіть копію поточного каталогу `/config/custom_components/solar_climate_manager` поза каталогом custom_components.
2. Замініть цей каталог однойменним каталогом з архіву. Не змінюйте `/config/.storage`: у ньому збережені записи та параметри HA.
3. Перезапустіть Home Assistant та оновіть сторінку браузера.
4. Відкрийте **Налаштування → Пристрої та служби → Інтеграції → Solar Climate Manager**. Видаляти й повторно додавати запис не потрібно.
5. Переконайтеся, що є сутність select із режимами disabled, observation, control, temporary_block. Початкове спостереження залишається без команд; повне управління потрібно вибрати самостійно.
6. [Картка для climate.1e64a41d](lovelace-card-1e64a41d.yaml) вже містить усі надані ID. Вставте її у ручну картку вашої панелі.

Існуючі entity_id можуть зберігати історичні назви; сам текст entity_id не доводить версію коду. Ознаки попереднього коду в наданому списку: режим має лише observation/disabled, датчик дії має старі варіанти дій і немає select режиму. Архів перевірено на цілісність і наявність поточних модулів; роботу фізичного кондиціонера тут не перевірено.
