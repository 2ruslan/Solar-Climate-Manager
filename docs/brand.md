# Solar Climate Manager icon

The icon combines an amber sun with a teal HVAC fan. It is generated with the built-in ImageGen tool and exported as transparent PNG assets:

- `custom_components/solar_climate_manager/brand/icon.png`: 256 × 256.
- `custom_components/solar_climate_manager/brand/icon@2x.png`: 512 × 512.

The same artwork works on light and dark backgrounds. The original generation was trimmed and resized for packaging; no separate logo is needed for this square mark.

Local brand assets are supported by Home Assistant 2026.3 and later. Marketplace discovery images depend on release/catalog indexing and caching; adding files to the repository does not immediately refresh every HACS client.

References:
- https://contributors.home-assistant.io/core/integrations/brands/
- https://contributors.home-assistant.io/marketplace/guides/integrations/#brand-images

## Generation prompt

Use case: logo-brand. Create one polished minimal icon for Solar Climate Manager, a Home Assistant integration that runs air conditioning using solar energy. A unified bold symbol: warm amber sun with a few short thick rays rising behind a teal stylized three-blade HVAC fan, clean circular geometry and balanced negative space. Flat vector-like raster artwork, crisp smooth edges, no gradients, no shadows, no text, no letters, no border, no app tile backdrop. Centered square composition, generous 10% padding, recognizable at 32 pixels. Only amber and medium teal shapes, suitable on white and dark gray interfaces. True transparent background. Single icon only.
